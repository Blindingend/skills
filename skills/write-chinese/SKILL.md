# Write Chinese

## 核心原则

把中文文本当作界面来写。每一句、每个修饰、每个转折都必须有用途。

写完后用两个问题检查：

1. 删掉这句话或这个词，意思是否有损失。
2. 读者追问“这具体指什么”时，是否能用事实或逻辑回答。

任一问题答不上，就删掉或改成更具体的说法。

## 写作流程

1. 先确认文本目的、读者、事实边界和必须保留的信息。
2. 写第一版时只表达必要事实、判断和行动，不靠语气撑强度。
3. 逐句做删除测试，删掉不改变含义的修饰、从句、铺垫和圆场。
4. 对抽象判断补具体依据。如果补不出来，降低判断强度。
5. 检查是否有假对立、夸大、黑话、花哨比喻和少见词。
6. 输出前确认标点、句式和用词都符合当代通用中文。

## 具体规则

不要强调正常读者不会误解的事。想写“不是 X”“并非 X”时，先判断 X 是否是读者真实可能产生的误解。如果不是，直接删掉这层澄清。

修饰必须承载信息。形容词、定语、背景从句删掉后，读者少知道了什么。如果答案不明确，就不要保留。

比喻、术语和概括说法必须经得起追问。只有在它比直白说法更帮助理解，并且能展开为具体事实或逻辑时才使用。否则改成直陈。

多余内容要删掉，不要补解释。发现某段内容需要额外限定才能站住时，先判断它是否本来就该存在。

不要制造假的对立。除非读者确实存在可指认的误解，否则不要写“不是 X，而是 Y”“不只是 X，更是 Y”。直接说 Y。

不要用夸大代替论证。重要性、影响和风险要落到事实、范围和后果上。无法支撑的强判断要降级。

用词和标点保持通用。优先使用普通读者一眼能懂的词。不用文言句式、生僻词、半文半白表达、破折号、间隔号、着重号，也不要用一两个字加冒号的小标签式行文。

## UI 文案

写按钮、提示、错误信息、空状态和设置项时，同样执行删除测试。

- 按钮写用户要执行的动作。
- 提示只说明当前状态、原因和可执行的下一步。
- 错误信息说明发生了什么、影响什么、用户能做什么。
- 空状态不要安慰用户，直接说明当前为空以及可用动作。
- 设置项名称优先写对象和动作，不写宣传式描述。

## 输出检查

交付中文文本前，确认：

- 没有为了显得认真、深刻或有文采而存在的句子。
- 每个判断都能对应事实、范围、条件或后果。
- 没有纯情绪词替代说明。
- 没有把简单意思包装成新词或术语。
- 文本读起来像一个正常人在清楚说事。
